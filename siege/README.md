# Breach Point

A small tactical shooter in the style of Rainbow Six Siege, in one HTML file (`index.html`, Three.js r128 from cdnjs). It is separate from the DIY Check-In app: nothing in `public/` or `server.js` serves or links to it.

Play: open `siege/index.html` in a desktop browser (keyboard and mouse).

- **Prep (30s):** drive a drone, find which room holds the device, click defenders to mark them.
- **Assault (2:30):** five AI defenders (3 anchors on site, 1 in an adjacent room, 1 roamer). Soft walls break into holes under fire, barricades fall to melee or bullets, steel walls need FORGE's thermal charge. Bullets go through soft walls and planks (wallbangs).
- **Win:** eliminate all five, or plant the defuser on the hazard square (hold F) and keep defenders off it for 35s. First to 3 rounds.
- **Operators:** RAZE (3 breaching charges), FORGE (thermal + breaching charge, more HP), MAUL (unlimited breaching hammer).
